# Arbeitszeit-Assistent v0.10.09 – Reparaturstand

Dieser Stand basiert auf der funktionierenden Kalender-/Datumsbasis v0.10.03. Die Dateien gehören zusammen und müssen gemeinsam veröffentlicht werden.

## Reparaturen
- Kalender und Tagesliste aus der stabilen Basis beibehalten.
- Tätigkeitsauswertung repariert; kein Zugriff mehr auf eine undefinierte Variable.
- Freie Tätigkeit nach dem letzten Komma wird übernommen, auch bei bisher unbekannten Begriffen.
- Ort wird bei kommaseparierter Eingabe aus dem mittleren Teil übernommen.
- Tätigkeitsbegriffe ergänzt: Gartenpflege, Baumpflege, Gehölzschnitt, Rasenmähen, Pflege sowie Pflasterarbeiten.
- Neue Versionskennung für App-Assets und Service-Worker-Cache.

## Veröffentlichung
Alle Dateien aus diesem ZIP gemeinsam in das Repository-Hauptverzeichnis hochladen und bestehende Dateien ersetzen. Nicht einzelne Dateien aus verschiedenen ZIP-Versionen mischen.
